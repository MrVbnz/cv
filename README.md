# Дмитрий Ефремов — резюме

Одностраничное резюме на React, TypeScript и Chakra UI 3. Сборка и локальный сервер — Vite. Содержание перенесено из исходных EN/RU страниц без актуализации данных.

## Запуск

Нужны Node.js 22.12+ и Yarn 1.22.22.

```sh
yarn install --frozen-lockfile
yarn dev
```

Локальный адрес: http://localhost:5173/cv/.

```sh
yarn typecheck  # Проверка TypeScript
yarn test       # Проверки выбора языка и структуры контента
yarn build      # Проверка TypeScript и production-сборка в dist/
yarn preview    # Просмотр собранной версии
```

Браузерные проверки:

```sh
yarn playwright install chromium
yarn build
yarn test:e2e
```

Для установленного Chrome можно задать `PLAYWRIGHT_CHANNEL=chrome`. Браузерные проверки покрывают переключение и сохранение языка, мобильное меню, определение языка браузера и работу без localStorage.

## Структура

- `src/data/locales/en.ts`, `ru.ts` — отдельные таблицы текстов, подписей интерфейса, ссылок и данных резюме.
- `src/data/types.ts` — общая типизированная схема. Допускает различия в составе контента языковых версий.
- `src/i18n/` — состояние языка, определение первоначального выбора и сохранение предпочтения.
- `src/components/sections/` — компоненты разделов резюме.
- `src/components/` — навигация, переключатель языка и общий контейнер раздела.
- `src/theme.ts` — палитра, шрифты и глобальные стили Chakra UI.
- `public/assets/` — фотография, иконки и манифест.

Пользовательские PNG-иконки находятся в `public/assets/icons/`. Каждый значок имеет варианты `24px`, `48px` и `64px`. Компонент `AssetIcon` отображает их в размере 24×24 CSS px и через `srcSet` подбирает файл под плотность экрана. Исходные изображения используются без фильтров. Библиотека иконок не требуется.

Язык переключается на той же странице без перезагрузки и изменения адреса. Приоритет: сохранённый выбор → первый поддерживаемый язык браузера → английский. Вместе с текстами меняются `html.lang`, заголовок страницы и описание. Переходы по разделам и смена языка прокручивают страницу к началу выбранного раздела без добавления якоря в адресную строку. Старые ссылки с якорями поддерживаются, после открытия якорь убирается из адреса.

При добавлении контента меняйте соответствующую языковую таблицу; компоненты не содержат текстов резюме. Новый язык требует таблицы, расширения типа `Locale`, списка языков и правил выбора в `src/i18n/locale.ts`.

## Размещение

Базовый путь `/cv/` задан в `vite.config.ts` для существующего GitHub Pages размещения. Для размещения в корне домена используйте `yarn build --base=/`. Старые отдельные страницы `ru.html` больше не создаются.

Существующий GitHub Actions workflow собирает `dist/` и публикует его при push в `main` или ручном запуске. В рамках локальной миграции публикация не выполняется.

На следующем этапе — актуализация содержания, согласование языковых версий и доработка визуальной презентации.
