# Дмитрий Ефремов — резюме

Одностраничное резюме на React, TypeScript и Chakra UI 3. Сборка и локальный сервер — Vite.

## Запуск и проверки

Нужны Node.js 22.12+ и Yarn 1.22.22.

```sh
yarn install --frozen-lockfile
yarn dev
```

Локальный адрес: http://localhost:5173/cv/.

```sh
yarn typecheck    # TypeScript, включая тесты и конфигурацию
yarn format:check # Проверка форматирования
yarn format       # Форматирование исходников и конфигурации
yarn test         # Выбор языка и целостность данных
yarn build        # Проверка TypeScript и сборка в dist/
yarn preview      # Просмотр сборки
```

Для браузерных тестов:

```sh
yarn playwright install chromium
yarn build
yarn test:e2e
```

Для установленного Chrome можно задать `PLAYWRIGHT_CHANNEL=chrome`. Проверяются обе версии сервера, переключение языка, прокрутка, мобильное меню, клавиатурная навигация, низкие окна и PNG для разных плотностей экрана. Тесты поднимают отдельные серверы на портах 4173 и 4183.

## Структура

- `src/data/locales/` — тексты, ссылки и данные резюме для каждого языка. Обе таблицы проверяются типом `ResumeData` из `src/data/types.ts`.
- `src/i18n/` — список поддерживаемых языков, выбор, хранение и метаданные страницы. Этот слой не управляет прокруткой.
- `src/hooks/useLanguageSelection.ts` — сохраняет текущий раздел до смены языка и возвращает к его началу после обновления разметки.
- `src/hooks/useActiveSection.ts` — следит за прокруткой, размером окна и изменениями размеров разделов.
- `src/utils/` — определение текущего раздела и прокрутка с необязательной передачей фокуса.
- `src/components/navigation/` — отдельные мобильная и боковая панели, общий список разделов.
- `src/components/sections/` — представление разделов резюме.
- `src/theme.ts` — цвета, шрифты, размеры панелей и длительности анимаций. `--header-height` участвует в высоте разделов и прокрутке; `--sidebar-width` задаёт ширину панели и отступ страницы.
- `public/assets/` — только используемые изображения и манифест.

Разделы занимают минимум один доступный экран, длинные растягиваются по содержимому. Разделитель рисуется поверх границы и не увеличивает высоту. На мобильном доступная высота учитывает верхнюю панель. Анимации меню и hamburger — 160 мс, языка — 80 мс; уменьшение движения учитывается системной настройкой.

PNG в `public/assets/icons/` имеют варианты 24/48/64 px. `AssetIcon` выводит их в размере 24×24 CSS px и подбирает файл через `srcSet`. Изображения используются без фильтров и библиотеки иконок.

Приоритет языка: сохранённый выбор → первый поддерживаемый язык браузера → английский. Переключение языка и выбор раздела не изменяют URL. Маршрутов языковых страниц, обработки старых якорей и редиректов нет.

Для обновления резюме меняйте языковые таблицы. Состав их контента может различаться. Идентификаторы записей описывают их смысл и сохраняются при перестановке. Для нового языка добавьте код в `src/i18n/locale.ts`, таблицу и запись в `src/data/index.ts`, затем обновите варианты выбора в таблицах.

## Размещение

Путь `/cv/` задан в `vite.config.ts` для GitHub Pages. Для корня домена: `yarn build --base=/`.

Workflow `.github/workflows/pages.yml` проверяет форматирование, тесты и сборку перед публикацией при push в `main` или ручном запуске. Локальные команды не выполняют публикацию.
